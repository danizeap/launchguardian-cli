# LaunchGuardian CLI v0.1.1

Patch release. First version published to PyPI (`pip install launchguardian`).

## Fixed
- Gate-name encoding bug: `SCANNER_GATES` and the disabled-scanner fallback contained
  double-encoded em-dashes, causing the same gate to be counted under two different
  strings depending on which code path produced the finding.

## Added
- Subprocess timeouts for external scanners (Gitleaks 300s, Semgrep 900s, Trivy 900s).
  A timed-out scanner now surfaces as a scanner execution failure (exit code 2)
  instead of hanging the CLI indefinitely.
- Regression test for the timeout path; version test now tracks `__version__`.
- MIT LICENSE file; PyPI metadata (classifiers, project URLs); GitHub Actions
  trusted-publishing workflow.
